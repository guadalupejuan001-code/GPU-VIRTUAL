# Evidencia original de C01

Estos archivos proceden del primer ensayo entregado en GPU-PROPIA-C01.zip.
Se conservan como registro de aquella compilacion y anfitrion. Los hashes de
los cinco archivos C++ en measurements.json permiten comparar el nucleo.

Las ejecuciones del repositorio escriben nuevos resultados en ../current/.
La comparacion temporal del ensayo original fue contra una referencia densa
CPU propia; no representa una comparacion con una GPU fisica.
